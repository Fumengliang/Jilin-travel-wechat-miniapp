# 吉林私旅管家 - 微信小程序（我们还未完成此项目）

> 免费智能旅行规划平台

## 项目介绍

「吉林私旅管家」是专为年轻人打造的免费智能旅行规划微信小程序，致力于解决三大痛点：
- **不敢放心消费** — 透明消费保障体系
- **不想费心规划** — AI智能推荐+精品路线
- **不知如何选择** — 大数据精准匹配

## 核心功能

| 功能 | 说明 |
|------|------|
| 🔍 随心搜 | AI智能推荐，输入目的地获取个性化方案 |
| 🗺️ 照着玩 | 精品路线，达人精心设计，一键直达 |
| ⚡ 动态调 | 自由随心，一键推迟/跳过，AI重规划 |
| 🎁 惊喜盒 | 低价好物盲盒，¥9.9起 |
| 🛡️ 透明保 | 明码标价，赔付基金兜底 |

## 技术栈

- **框架**: 微信小程序原生开发
- **样式**: WXSS + CSS变量
- **数据**: 本地Storage + 预留API接口

## 项目结构

```
jilin-travel-miniapp/
├── app.js                 # 全局逻辑
├── app.json               # 全局配置（含tabBar）
├── app.wxss               # 全局样式
├── project.config.json    # 项目配置
├── utils/
│   └── api.js             # API接口封装
└── pages/
    ├── index/             # 首页
    ├── search/            # 随心搜
    ├── routes/            # 精品路线列表
    ├── route-detail/      # 路线详情
    ├── itinerary/         # 动态行程
    ├── blindbox/          # 惊喜盲盒
    ├── transparency/      # 透明消费
    └── profile/           # 个人中心
└── images/
    └── 10种图标           # 个人中心
```

## 快速开始

1. 下载项目代码
2. 使用微信开发者工具导入项目
3. 填写 `project.config.json` 中的 `appid`
4. 点击编译即可预览

## 后续开发建议

### 后端接口对接
- 将 `utils/api.js` 中的 `BASE_URL` 替换为实际后端地址
- 接入微信支付实现盲盒购买
- 接入微信登录获取用户信息

### 功能扩展
- 接入地图SDK实现路线导航
- 接入AI推荐算法（如腾讯云智能推荐）
- 增加社交分享功能
- 接入酒店/门票预订API

### 图片资源
- 当前使用占位图片（picsum.photos）
- 建议替换为实际景点高清图片
- 准备tabBar图标（已完成）
